# YaVoice • Перевод видео YouTube как на ПК (Оригинал 0%)

Веб-сервис для перевода и озвучки видео YouTube с помощью нейросетевого перевода Яндекса (`VOT API`), созданный специально для смартфонов и ПК:
- **🔇 Режим ПК (Оригинал 0%)**: полностью выключает оригинальную звуковую дорожку YouTube, оставляя только чистую русскую озвучку.
- **🧠 Умное приглушение (Smart Ducking)**: автоматически снижает громкость оригинала до `0%` во время речи русского диктора и плавно возвращает звук в паузах.
- **🎚️ Ручной микшер**: отдельные ползунки громкости перевода (`0–150%`) и оригинала (`0–100%`).
- **💬 Синхронные нейро-субтитры** и скачивание `.MP3` / `.SRT`.

## Деплой в Cloudflare Pages (за 30 секунд)

Проект полностью собран и готов к работе на **Cloudflare Pages** (включая серверные **Cloudflare Pages Functions** в папке `functions/api/` и браузерный бандл `public/vot-client.bundle.js`):

1. Откройте [Cloudflare Dashboard → Workers & Pages](https://dash.cloudflare.com/?to=/:account/workers-and-pages/create/pages).
2. Выберите вкладку **Pages** → **Connect to Git** и выберите репозиторий **`David12-45/yavoice-pc-translator`**.
3. В настройках сборки укажите:
   - **Framework preset**: `None`
   - **Build command**: *(оставьте пустым — все бандлы уже собраны)*
   - **Build output directory**: `public`
4. Нажмите **Save and Deploy** — ваш сервис сразу откроется на домене `*.pages.dev` и будет работать на телефоне и ПК!
